# IP 주소 & 서브넷 계산

> [!important] 출제 빈도 ★★★★★
> 매 회차 1~2문제. 네트워크 주소 계산, 사용 가능 호스트 수, 브로드캐스트 주소

---

## 서브넷 계산 공식

```
네트워크 주소 = IP주소 AND 서브넷마스크  (비트 AND 연산)
브로드캐스트  = 네트워크주소 | (NOT 서브넷마스크)
호스트 수     = 2^(호스트비트수) - 2  (네트워크, 브로드캐스트 제외)
```

---

## 서브넷 마스크 → CIDR 변환표

| 서브넷 마스크 | CIDR | 호스트 비트 | 사용 가능 호스트 수 |
|--------------|------|-----------|----------------|
| 255.255.255.0 | /24 | 8 | 254 |
| 255.255.255.128 | /25 | 7 | 126 |
| 255.255.255.192 | /26 | 6 | **62** |
| 255.255.255.224 | /27 | 5 | 30 |
| 255.255.255.240 | /28 | 4 | 14 |
| 255.255.254.0 | /23 | 9 | 510 |
| 255.255.252.0 | /22 | 10 | 1022 |
| 255.255.0.0 | /16 | 16 | 65534 |

---

## 계산 예시 1: 255.255.255.192 = /26

```
IP: 223.13.234.132
서브넷: 255.255.255.192

132 = 10000100
192 = 11000000
AND = 10000000 = 128

네트워크 주소: 223.13.234.128
브로드캐스트:  223.13.234.191 (128+64-1)
사용 가능 호스트: 2^6 - 2 = 62개
```

> [!example] 기출 (2025년 2회차 6번)
> ① 128, ② 62

---

## 계산 예시 2: 255.255.254.0 = /23

```
IP-a: 192.168.11.20
IP-b: 192.168.12.200
서브넷: 255.255.254.0

11 = 00001011,  254 = 11111110
AND = 00001010 = 10
→ 네트워크: 192.168.10.0/23

12 = 00001100, 254 = 11111110
AND = 00001100 = 12
→ 네트워크: 192.168.12.0/23
```

> [!example] 기출 (2026년 1회차 11번)
> a. 192.168.10.0/23
> b. 192.168.12.0/23

---

## 계산 예시 3: 255.255.252.0 = /22

```
IP: 192.168.35.10
서브넷: 255.255.252.0

35 = 00100011,  252 = 11111100
AND = 00100000 = 32

네트워크: 192.168.32.0
브로드캐스트: 192.168.35.255

같은 네트워크 = 192.168.32.0 ~ 192.168.35.255 범위
```

> [!example] 기출 (2025년 1회차 9번)
> 보기에서 192.168.32.0~35.255 범위인 것 모두 선택 → ㄱ,ㄴ,ㄷ,ㄹ,ㅁ 모두 해당

## 비트 AND 연산 빠른 계산

| 마지막 옥텟 값 | 마스크 | 계산 |
|--------------|--------|------|
| 임의 값 X | 255 | X AND 255 = X (그대로) |
| 임의 값 X | 0 | X AND 0 = 0 |
| 임의 값 X | 192 (11000000) | X AND 192 → 0,64,128,192 중 하나 |
| 임의 값 X | 254 (11111110) | X AND 254 → 짝수 결과 |
| 임의 값 X | 252 (11111100) | X AND 252 → 4의 배수 결과 |

> [!tip] 마스크가 0인 옥텟은 무조건 0, 마스크가 255인 옥텟은 IP 그대로

## NAT (Network Address Translation)

- IP 패킷에서 **공인 IP주소 ↔ 내부 사설 IP주소** 변환
- 라우터를 통해 네트워크 트래픽 처리
- 내부 IP를 숨겨 보안 향상, IP 부족 문제 해결

> [!example] 기출 (2023년 3회차 12번)

## ARP / RARP

| 프로토콜 | 방향 | 설명 |
|----------|------|------|
| **ARP** | IP → MAC | IP 주소로 MAC 주소 조회 |
| **RARP** | MAC → IP | MAC 주소로 IP 주소 조회 |

> [!example] 기출 (2025년 1회차 6번)
> (1) ARP: IP→MAC, (2) RARP: MAC→IP
