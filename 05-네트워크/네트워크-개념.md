# 네트워크 개념

---

## OSI 7계층

```
7. 응용 계층 (Application)    — HTTP, FTP, SMTP, DNS
6. 표현 계층 (Presentation)   — 암호화/복호화, 코드 변환
5. 세션 계층 (Session)        — 세션 설정/유지/종료
4. 전송 계층 (Transport)      — TCP, UDP, 포트 번호, 세그먼트
3. 네트워크 계층 (Network)    — IP, 라우터, 패킷
2. 데이터링크 계층 (Data Link)— MAC, 스위치, 프레임, HDLC
1. 물리 계층 (Physical)       — 비트 전송, 허브, 케이블
```

> [!tip] 암기: **응표세전네데물** (아래→위 외우면 더 쉬움: 물데네전세표응)

> [!example] 기출 (2025년 2회차 9번)
> TCP/IP 4계층: 응용 / 전송 / 인터넷 / 네트워크 접속(링크)

## TCP vs UDP

| 항목 | TCP | UDP |
|------|-----|-----|
| 연결 | 연결 지향 (3-way handshake) | 비연결 |
| 신뢰성 | 보장 (흐름/오류 제어) | 미보장 |
| 속도 | 느림 | 빠름 |
| 용도 | 파일 전송, HTTP | 동영상 스트리밍, DNS |

> [!example] 기출 (2024년 1회차 15번)
> "연결 지향, 3-way handshake, 흐름/오류 제어" → **TCP**
> "비연결, 데이터그램 방식" → **UDP**

## URL 구조

```
https://www.example.com:8080/path/page.html?key=val#section
└──┘   └──────────────┘└──┘└─────────────┘└───────┘└──────┘
프로토콜    도메인(호스트)  포트    경로(Path)    쿼리스트링  앵커
```

| 구성요소 | 설명 |
|---------|------|
| **프로토콜** | http, https, ftp 등 |
| **도메인** | 서버 식별 (DNS로 IP 변환) |
| **포트** | 기본 http=80, https=443, 생략 가능 |
| **경로** | 서버 내 리소스 위치 |
| **쿼리스트링** | `?key=value&key2=value2` — 서버에 전달할 파라미터 |
| **앵커(Fragment)** | `#id` — 페이지 내 특정 위치 이동 |

> [!example] 기출 (2025년 3회차 3번)
> URL에서 포트 번호를 지정하는 구분자 → **:`포트번호`**

## AJAX (Asynchronous JavaScript And XML)

- **비동기 방식**으로 서버와 데이터 교환
- 페이지 **전체 새로고침 없이** 일부만 업데이트
- `XMLHttpRequest` 객체 또는 `fetch()` API 사용
- 실제로는 XML보다 **JSON** 많이 사용

> [!example] 기출 (2023년 3회차 8번)
> "비동기 방식으로 웹 페이지 일부만 갱신" → **AJAX**

---

## REST API

| 특징 | 설명 |
|------|------|
| **무상태(Stateless)** | 각 요청은 독립적, 서버가 클라이언트 상태 저장 X |
| **자원 기반** | URI로 자원 식별 (`/users/1`) |
| **HTTP 메서드** | GET(조회) / POST(생성) / PUT(수정) / DELETE(삭제) |
| **클라이언트-서버** | 역할 분리 |

## IPv6

- **128비트** 주소 (IPv4는 32비트)
- **16진수** 8그룹 표기 (콜론 구분)
- NAT 없이 충분한 주소 공간
- IPSec 기본 내장

> [!example] 기출 (2024년 2회차 3번)
> "128비트 주소, IPv4 부족 해결" → **IPv6**

## Ad-hoc 네트워크

- **기지국(Access Point) 없이** 단말 간 직접 통신
- 임시 구성, 자율 구성 네트워크
- 재난/군사 환경에서 활용

> [!example] 기출 (2024년 3회차 5번)
> "기지국 없이 노드 간 직접 통신, 자기 구성(self-organizing)" → **Ad-hoc**

---

## 블루투스 (Bluetooth)

- 근거리 무선 통신 (10m 내외)
- 2.4GHz 주파수대역 사용
- **피코넷(Piconet)**: 마스터 1개 + 슬레이브 최대 7개
- **스캐터넷(Scatternet)**: 피코넷 여러 개 연결

## 기타 프로토콜 포트 번호

| 프로토콜 | 포트 | 용도 |
|---------|------|------|
| HTTP | 80 | 웹 |
| HTTPS | 443 | 보안 웹 |
| FTP | 21(제어) / 20(데이터) | 파일 전송 |
| SSH | **22** | 암호화 원격 접속 |
| Telnet | 23 | 원격 접속 (비암호화) |
| SMTP | 25 | 이메일 발신 |
| DNS | 53 | 도메인→IP 변환 |
| DHCP | 67/68 | IP 자동 할당 |

> [!example] 기출 (2025년 1회차 4번, 2024년 2회차 11번)
> SSH 포트 → **22**
