# 빠르게노트 — 보안

> [!note] 쓰는 법
> 단답식은 **설명을 보고 이름을 떠올리는** 싸움이다. 표의 왼쪽(키워드)만 보고 오른쪽을 말해 보자. ⚠️ = 실제로 틀렸던 것.

## 1. DoS 계열 — "서비스가 마비된다"

| 키워드 | 정답 |
|---|---|
| SYN만 대량, ACK 안 보냄, 대기 큐 고갈 | **SYN Flooding** |
| ⚠️ 출발지를 피해자로 위장 + **브로드캐스트** + ICMP Echo → 응답이 몰림 | **Smurf** (Spoofing은 *수법*이지 공격 이름 아님) |
| ⚠️ **출발지 IP = 목적지 IP** | **Land Attack** |
| 허용 크기보다 **큰 ICMP 패킷** | **Ping of Death** |
| Fragment **오프셋 조작** → 재조립 불가 | **Teardrop** |
| 좀비 PC 여러 대로 동시 공격 | **DDoS** |

> [!warning] 워터링 홀은 DoS가 아니다
> "몰린다 / 마비된다" 설명에 워터링 홀을 붙이는 실수가 두 번 나왔다.

## 2. 표적 공격 / 속이기

| 키워드 | 정답 |
|---|---|
| 표적이 **자주 가는 정상 사이트**에 악성코드 | **워터링 홀** |
| 명확한 표적, **장기간**, 침투→검색→수집→유출 | **APT** |
| ⚠️ 정상 URL 입력해도 **DNS/hosts 변조**로 가짜 사이트 | **파밍** |
| 가짜 메일·링크 / 특정인 맞춤 | **피싱** / **스피어 피싱** |
| 문자(SMS) / QR코드 | **스미싱** / **큐싱** |
| 시퀀스 번호 조작, **세션 가로채기** | **세션 하이재킹** |
| 임시 파일을 특수 파일로 바꿔치기 (Race Condition) | **심볼릭 링크 공격** |
| 패치 나오기 **전** 취약점 공격 | **제로데이** |

## 3. 웹 공격 ⚠️

| 키워드 | 정답 | 무엇을 믿는 점을 악용하나 |
|---|---|---|
| 게시판에 **스크립트** 심어 **다른 사용자 브라우저**에서 실행 | **XSS** | 사용자 → 사이트를 믿음 |
| **로그인된 사용자 권한**으로 위조 요청(송금·비번 변경) | **CSRF** | 서버 → 사용자를 믿음 |
| 입력값에 **SQL** 삽입 | **SQL Injection** | DB 쿼리 |

> [!tip] 구분
> **스크립트가 실행**되면 XSS, **요청이 대신 전송**되면 CSRF.

## 4. 악성코드

| 키워드 | 정답 |
|---|---|
| 자가복제 O, **숙주 파일 필요** | **바이러스** |
| 자가복제 O, **독자 실행 + 네트워크 전파** | **웜** |
| 정상 프로그램 위장, 자가복제 X, 백도어 | **트로이목마** |
| **존재를 숨김**, 시스템콜 조작 | **루트킷** |
| 가짜 바이러스 경고로 결제·설치 유도 | **스캐어웨어** |
| 파일 암호화 후 돈 요구 | **랜섬웨어** |

## 5. 암호

- **대칭키**: DES(56비트) · 3DES · **AES**(NIST, 128/192/256) · SEED · ARIA(둘 다 국산)
- **비대칭키**: **RSA**(소인수분해) · **ECC**(타원곡선, 짧은 키) · ⚠️ **Diffie-Hellman**(1976, **키 교환**, 이산대수) · ElGamal(이산대수)
- **해시**: 고정 길이 출력, 단방향. MD5 · SHA

## 6. 프로토콜 / 접근제어

- **IPSec**(3계층): **AH** = 인증·무결성만 / **ESP** = 암호화까지 / **IKE** = 키 교환. 전송 모드(페이로드만) vs 터널 모드(패킷 전체)
- **SSH**: 원격 접속, 포트 22
- **OAuth**: 토큰으로 제3자 앱에 권한 위임 / **OTP**: 일회용 비밀번호
- **MAC**: 보안 등급(관리자 강제) / **DAC**: 소유자가 부여 / **RBAC**: 역할 기준
- **CIA**: 기밀성 · 무결성 · 가용성
- **ISMS**: 정보보호 관리체계
