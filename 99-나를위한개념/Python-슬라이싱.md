# Python 슬라이싱 — `[i:j]`부터 `[i:j:k]`까지

> [!note] 이 노트를 만든 이유
> 처음 Python을 배울 때 `[i:j]` 형태만 봐서, `[-4:-1:2]`처럼 **음수 + 콜론 두 개**가 나오자 머리가 멈췄다.
> 이 노트는 "어떤 모양의 슬라이싱이 나와도 **같은 순서로** 손으로 풀 수 있게" 만드는 것이 목표다.

---

## 0. 먼저 인덱스부터

예제 리스트는 이 노트 전체에서 계속 쓴다.

```python
a = [10, 20, 30, 40, 50, 60]
```

| 값 | 10 | 20 | 30 | 40 | 50 | 60 |
|----|----|----|----|----|----|----|
| 양수 인덱스 | 0 | 1 | 2 | 3 | 4 | 5 |
| 음수 인덱스 | -6 | -5 | -4 | -3 | -2 | -1 |

- **-1은 항상 마지막 원소**다. "뒤에서 1번째"라고 읽는다.
- 음수 → 양수 변환 공식: **음수 + 길이** → `-4 + 6 = 2`

> [!tip] 왜 -1이 마지막일까?
> `a[-1]`은 사실 `a[len(a) - 1]`의 줄임말이다. 길이가 몇이든 "끝에서 몇 번째"를 바로 쓰기 위해 만든 문법이다.
> 그래서 -0은 없다(0은 맨 앞). 끝에서 세면 **-1부터** 시작한다.

---

## 1. 콜론 1개 — `a[i:j]`

### 규칙 한 줄
> **i부터 j 바로 앞까지** (i는 포함, j는 미포함)

```python
a[1:4]    # 인덱스 1, 2, 3     → [20, 30, 40]
a[0:2]    # 인덱스 0, 1        → [10, 20]
```

### 생략하면?
| 쓴 것 | 의미 | 결과 |
|------|------|------|
| `a[:3]` | 처음부터 3 앞까지 | `[10, 20, 30]` |
| `a[3:]` | 3부터 끝까지 | `[40, 50, 60]` |
| `a[:]` | 처음부터 끝까지 (전체 복사) | `[10, 20, 30, 40, 50, 60]` |

### 음수가 섞이면 → 먼저 양수로 바꾼다
```python
a[-2:]    # -2 → 4,  4부터 끝까지        → [50, 60]   (뒤에서 2개)
a[:-2]    # -2 → 4,  처음부터 4 앞까지   → [10, 20, 30, 40]   (뒤에서 2개 빼고)
a[-4:-1]  # 2부터 5 앞까지 (2, 3, 4)    → [30, 40, 50]
```

### 결과 개수 빠르게 세기
콜론 1개(step 생략)일 때는 **개수 = j − i**다. `a[1:4]` → 4 − 1 = 3개.

> [!tip] 왜 end를 미포함으로 만들었을까?
> - `a[:3]` + `a[3:]` = 원래 리스트 전체. 자르는 지점 하나(3)로 깔끔하게 반반 나뉜다.
> - 개수가 `j - i`로 바로 나온다.
> - Java의 `substring(begin, end)`, C의 `for (i = 0; i < n; i++)`도 같은 방식이다. 이걸 **반열린 구간 [i, j)** 이라고 부른다.

### i가 j보다 크면? → 빈 리스트
```python
a[4:2]    # 오른쪽으로 가야 하는데 4에서 2로는 못 감 → []
```

## 2. 콜론 2개 — `a[i:j:k]`

### 규칙 한 줄
> **i에서 출발해서 k칸씩 이동하고, j에 닿기 전에 멈춘다.**

`k`는 "몇 칸씩 건너뛸지(step)"다. 콜론 1개짜리는 사실 `k = 1`이 생략된 것이다.

```python
a[1:5:2]   # 1 → 3 → (5는 j라서 멈춤)       → [20, 40]
a[::2]     # 0 → 2 → 4 → (6은 범위 밖)      → [10, 30, 50]
a[1::2]    # 1 → 3 → 5                     → [20, 40, 60]
```

### 손으로 푸는 3단계 루틴 ⭐
1. **음수 인덱스를 양수로 바꾼다** (음수 + 길이)
2. **생략된 값을 채운다** (아래 표)
3. **i부터 k씩 더하며 나열하고, j에 닿거나 넘으면 멈춘다** (j는 미포함)

> [!example] 10/06 Q1 다시 풀기 — `a[-4:-1:2]`
> 1. `-4 → 2`, `-1 → 5` → `a[2:5:2]`
> 2. 생략된 값 없음
> 3. 2 → 4 → (6은 5를 넘음, 멈춤) → 인덱스 2, 4 → **`[30, 50]`**
>
> 내가 고른 `[20, 40]`은 출발점을 인덱스 1(=-5)로 잡은 것이다. **1단계 변환을 빼먹으면 이렇게 된다.**

> [!question] 그럼 여기서 end(-1)는 뭘 한 거야?
> 이 문제에서는 **결과를 바꾸지 않았다.** step이 2라서 4 다음은 6인데, 6은 어차피 리스트 밖이다.
> end가 결과를 바꾸는 경우와 비교해 보자.
> - `a[-4:-2:2]` → `a[2:4:2]` → 2 → (4는 j, 멈춤) → `[30]` ← end가 50을 막았다
> - `a[-4:-1]` → `a[2:5]` → 2, 3, 4 → `[30, 40, 50]` ← end가 60을 막았다
>
> 즉, **end는 "여기서 멈춰"라는 울타리**다. 울타리 앞에서 이미 끝나면 아무 일도 하지 않는다.

## 3. step이 음수면 → 거꾸로 간다

### 규칙 한 줄
> **i에서 출발해서 왼쪽(←)으로 |k|칸씩 이동하고, j에 닿기 전에 멈춘다.**

```python
a[::-1]     # 전체 뒤집기                        → [60, 50, 40, 30, 20, 10]
a[::-2]     # 5 → 3 → 1                         → [60, 40, 20]
a[4:1:-1]   # 4 → 3 → 2 → (1은 j, 멈춤)          → [50, 40, 30]
a[-1:-4:-1] # 5 → 4 → 3 → (2는 j, 멈춤)          → [60, 50, 40]
```

### ⚠️ 생략값이 방향에 따라 바뀐다

| | step이 양수 (→) | step이 음수 (←) |
|---|---|---|
| start 생략 | **맨 앞** (0) | **맨 끝** (-1) |
| end 생략 | 맨 끝 **너머**까지 | 맨 앞 **너머**까지 (0도 포함) |

"생략하면 **진행 방향의 출발점부터 끝까지** 간다"라고 기억하면 된다.

### 음수 step에서 자주 틀리는 것
```python
a[1:4:-1]   # 1에서 왼쪽으로 가는데 4는 오른쪽에 있음 → []
a[0::-1]    # 0에서 왼쪽으로 → 더 갈 곳 없음 → [10]
a[:2:-1]    # 끝(5)에서 왼쪽으로, 2 앞까지 → 5, 4, 3 → [60, 50, 40]
```
> 방향(step 부호)과 i → j 방향이 **반대면 무조건 빈 리스트**다.

## 4. 인덱싱 vs 슬라이싱 — 범위를 벗어나면?

| | 인덱싱 `a[i]` | 슬라이싱 `a[i:j]` |
|---|---|---|
| 꺼내는 것 | 원소 **1개** | 원소 **묶음** (리스트) |
| 범위 밖이면 | **IndexError** | 에러 없이 **있는 만큼만** (없으면 `[]`) |

```python
a[10]       # IndexError: list index out of range
a[10:20]    # []
a[4:100]    # [50, 60]   ← 100까지 없지만 있는 데까지만
```

> [!tip] 왜 다를까?
> - 인덱싱은 "값 **하나**를 내놔"다. 그 자리에 아무것도 없으면 줄 게 없으니 에러가 난다.
> - 슬라이싱은 "이 범위에 **있는 것들**을 담아 줘"다. 없으면 빈 상자를 주면 된다.

## 5. 문자열도 똑같다

리스트를 자르면 리스트, **문자열을 자르면 문자열**이 나온다. 규칙은 완전히 같다.

```python
s = "PYTHON"     # P0 Y1 T2 H3 O4 N5
s[1:4]           # "YTH"
s[-3:]           # "HON"
s[::2]           # "PTO"
s[::-1]          # "NOHTYP"
```

> 정처기에서는 **문자열 슬라이싱 + `+`로 이어 붙이기**가 단골이다.
> 예: [[../01-프로그래밍/Python-핵심|Python-핵심]]의 2023년 2회 "engneing" 기출

## 6. 집착토끼용 — 같이 알아두면 이해가 단단해지는 것

> [!info]- ① 슬라이싱은 "새 리스트"를 만든다 (복사)
> ```python
> a = [1, 2, 3]
> b = a[:]       # 새 리스트
> b[0] = 99
> print(a)       # [1, 2, 3]  ← 원본 그대로
>
> c = a          # 같은 리스트를 가리킴 (복사 아님!)
> c[0] = 99
> print(a)       # [99, 2, 3] ← 원본이 바뀜
> ```
> 단, 리스트 **안에 리스트**가 있으면 안쪽은 공유된다(얕은 복사). 2026년 1회 14번 기출이 바로 이 함정이다 → [[../01-프로그래밍/Python-핵심|Python-핵심]]의 "얕은 복사"

> [!info]- ② `range()`도 같은 규칙이다
> `range(start, stop, step)`도 **stop 미포함 + step 방향** 규칙이 똑같다.
> ```python
> list(range(1, 10, 3))   # [1, 4, 7]
> list(range(5, 0, -2))   # [5, 3, 1]
> ```
> 슬라이싱이 익숙해지면 `for i in range(...)` 반복 횟수도 같이 빨라진다.

> [!info]- ③ 슬라이스로 "대입"도 할 수 있다
> ```python
> a = [1, 2, 3, 4, 5]
> a[1:3] = [20, 30]      # [1, 20, 30, 4, 5]
> a[1:3] = []            # [1, 4, 5]   ← 구간 삭제
> ```
> 출제 빈도는 낮지만, 코드에 나오면 "그 구간을 통째로 갈아 끼운다"로 읽으면 된다.

> [!info]- ④ 튜플·문자열은 잘라 볼 수는 있지만 바꿀 수는 없다
> `s = "ABC"; s[0] = "Z"` → **TypeError** (문자열은 불변)
> 바꾸고 싶으면 `s = "Z" + s[1:]`처럼 **새로 만들어야** 한다.

## 7. 연습문제 (정처기 실기 난이도)

> 답은 접혀 있다. **3단계 루틴**을 종이에 써 가며 풀어 보자.

**P1.** 출력 결과는?
```python
s = "INFORMATION"
print(s[2:6] + s[-3:])
```
> [!success]- 정답
> **FORMION** — `s[2:6]` = F O R M, `s[-3:]` = I O N

**P2.** 출력 결과는?
```python
lst = [1, 2, 3, 4, 5, 6, 7, 8]
print(lst[1::3])
```
> [!success]- 정답
> **[2, 5, 8]** — 인덱스 1 → 4 → 7

**P3.** 출력 결과는?
```python
lst = list(range(10))
print(sum(lst[-3:]) - sum(lst[:3]))
```
> [!success]- 정답
> **21** — `[7, 8, 9]` 합 24 − `[0, 1, 2]` 합 3

**P4.** 출력 결과는?
```python
s = "ABCDEFG"
print(s[5:1:-2])
```
> [!success]- 정답
> **FD** — 인덱스 5(F) → 3(D) → 1은 j라서 멈춤

**P5.** 출력 결과는?
```python
a = [10, 20, 30, 40, 50]
print(a[::-1][1:4])
```
> [!success]- 정답
> **[40, 30, 20]** — 먼저 뒤집기 `[50, 40, 30, 20, 10]` → 그다음 `[1:4]` = 인덱스 1, 2, 3
> 슬라이싱이 두 번 붙어 있으면 **왼쪽부터 차례로** 적용한다.

**P6.** 두 줄 각각의 결과는?
```python
a = [1, 2, 3]
print(a[5:])
print(a[5])
```
> [!success]- 정답
> 첫 줄 **`[]`**, 둘째 줄 **IndexError** — 슬라이싱은 있는 만큼만, 인덱싱은 없으면 에러

## 한 장 요약

> [!summary]
> 1. 음수 인덱스 = 음수 + 길이 (-1 = 마지막)
> 2. `[i:j]` = i부터 **j 바로 앞까지**, 개수 = j − i
> 3. `[i:j:k]` = i에서 출발해 k칸씩, **j에 닿기 전에 멈춤**
> 4. k가 음수면 ←, 생략값도 반대(start = 끝, end = 맨 앞 너머)
> 5. 방향이 안 맞으면 `[]`, 슬라이싱은 범위 밖도 에러 없음, 인덱싱은 IndexError
