# 응집도 (Cohesion) & 결합도 (Coupling)

> [!important] 출제 빈도 ★★★★
> 거의 매 회차 출제. 설명 → 종류 이름, 또는 높은 순서대로 나열

---

## 응집도 (Cohesion) — 높을수록 좋음

> 하나의 모듈이 하나의 기능에 집중하는 정도

### 순서 암기 (높은 → 낮은)

```
기능적 > 순차적 > 교환적(통신적) > 절차적 > 시간적 > 논리적 > 우연적
```

> [!tip] 암기법: **기순교절시논우** 
> 기능을 순차로 교환하는 절차는 시간이 논리적이고 우연히 이루어진다

### 응집도 7가지 상세 설명

| 등급 | 이름 | 설명 | 키워드 |
|------|------|------|--------|
| 1위 | **기능적 (Functional)** | 모든 기능이 단일한 목적을 위해 수행 | "단일 목적", "모든 기능" |
| 2위 | **순차적 (Sequential)** | 앞 기능 출력 → 다음 기능 입력 | "파이프라인", "출력→입력" |
| 3위 | **교환적/통신적 (Communication)** | 같은 입출력으로 다른 기능 수행 | "동일 입출력", "서로 다른 기능" |
| 4위 | **절차적 (Procedural)** | 다수 기능이 순차적으로 수행, but 연관성 약함 | "순서 관계", "흐름" |
| 5위 | **시간적 (Temporal)** | 특정 시간에 함께 실행되는 기능 묶음 | "초기화", "종료 시", "함께 실행" |
| 6위 | **논리적 (Logical)** | 논리적으로 비슷한 기능들을 묶음 | "유사 기능", "매개변수로 선택" |
| 7위 | **우연적 (Coincidental)** | 기능 간 아무 관련 없음 | "관련 없음", "임의" |

> [!example] 기출 (2026년 1회차 20번)
> - "모듈이 다수의 관련 기능을 가질 때, 구성요소들이 그 기능을 **순차적으로 수행**" → **절차적**
> - "**동일한 입력과 출력**을 사용하여 서로 **다른 기능**을 수행하는 활동들" → **교환적**
> - "모듈 내부 **모든 기능이 단일한 목적**" → **기능적**

> [!example] 기출 (2024년 1회차 3번)
> 보기: ㄱ.기능 ㄴ.교환 ㄷ.우연 ㄹ.시간 → 높은 순서: **ㄱ, ㄴ, ㄹ, ㄷ**

## 결합도 (Coupling) — 낮을수록 좋음

> 두 모듈 간의 의존도 (낮을수록 독립적 = 좋음)

### 순서 암기 (낮은 → 높은)

```
자료 < 스탬프 < 제어 < 외부 < 공통 < 내용
```

> [!tip] 암기법: **자스제외공내**
> 자스가 제외된 공간에서 내가 혼자

### 결합도 6가지 상세 설명

| 등급 | 이름 | 설명 | 키워드 |
|------|------|------|--------|
| 1위 | **자료 (Data)** | 단순 값(파라미터)만 전달 | "파라미터", "단순 데이터" |
| 2위 | **스탬프 (Stamp)** | 배열, 객체, 자료구조 전달 | "오브젝트 전달", "구조체" |
| 3위 | **제어 (Control)** | 제어 신호(플래그)를 전달해 흐름 제어 | "플래그", "제어 요소 전달" |
| 4위 | **외부 (External)** | 외부에서 선언된 변수를 공유 | "외부 선언 변수" |
| 5위 | **공통 (Common)** | 전역 변수 공유 | "전역 변수", "갱신" |
| 6위 | **내용 (Content)** | 다른 모듈 내부 변수/기능에 직접 접근 | "내부 변수 접근", "코드 수정" |

> [!example] 기출 (2025년 1회차 12번)
> - "다른 모듈 내부에 있는 변수나 기능을 다른 모듈에서 사용" → **내용 결합도**
> - "인터페이스로 배열이나 오브젝트, 자료구조 등이 전달" → **스탬프 결합도**
> - "파라미터가 아닌 외부 선언 전역 변수를 참조하고 갱신" → **공통 결합도**

> [!example] 기출 (2024년 2회차 16번, 2024년 3회차)
> - "어떤 모듈이 다른 모듈의 논리적 흐름을 제어하기 위해 제어 요소 전달" → **제어 결합도**

---

## 핵심 정리

> [!summary] 한눈에 보기
> - **응집도 ↑** 좋음 → **기능적**이 최고
> - **결합도 ↓** 좋음 → **자료 결합도**가 최고
> - 좋은 모듈 설계: **높은 응집도 + 낮은 결합도**
