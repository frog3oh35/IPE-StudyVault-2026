> [!important] 출제 빈도 ★★★★
> 커버리지 종류 식별, 스텁/드라이버 구분, 테스트 케이스 구성요소

## 테스트 커버리지 (Coverage)

### 구조 기반 (화이트박스) 커버리지

| 커버리지 | 기준 | 설명 | 키워드 |
|----------|------|------|--------|
| **문장(Statement)** | 모든 문장 1회 이상 실행 | 가장 기본 | "모든 문장", "구문 커버리지" |
| **분기(Branch)** | 모든 분기 참/거짓 각 1회 | = 결정 커버리지 | "모든 분기", "결정포인트" |
| **조건(Condition)** | 각 **개별 조건식** 참/거짓 각 1회 | 결정과 다름! | "개별 조건식", "각각" |
| **조건/결정** | 조건 + 결정 동시 만족 | | |
| **MC/DC** | 각 조건이 **독립적으로** 결과에 영향 | 변경 조건/결정 | "독립적", "각 파라미터 적어도 1번" |
| **다중 조건** | 모든 조건 **조합** 테스트 | 경우의 수 최다 | "모든 조합" |
| **경로(Path)** | 가능한 모든 실행 경로 | | |

> [!warning] 조건 커버리지 ≠ 결정 커버리지
> `if (A && B)` 에서:
> - **결정**: 전체식이 T/F 각 1번
> - **조건**: A가 T/F 각 1번, B가 T/F 각 1번 (독립적으로)
> - 조건을 만족해도 결정을 만족하지 않을 수 있음

> [!example] 기출 (2025년 3회차 2번)
> "결정 포인트 내 모든 **개별 조건식**을 대상으로 참/거짓 모두 수행" → **조건(Condition) 커버리지**

> [!example] 기출 (2024년 1회차 13번)
> 1. 모든 문장 1회 이상 → **문장 커버리지**
> 2. 모든 분기 각 한 번 → **분기 커버리지**
> 3. 복합 조건 내 각 개별 조건 참/거짓 → **조건 커버리지**

> [!example] 기출 (2023년 2회차 6번)
> "결정포인트 내 모든 각 개별 조건식에 대한 모든 가능한 결과(참/거짓)" → **조건 커버리지**

## 분기 커버리지 순서 찾기

```
제어흐름 그래프에서 분기 커버리지를 만족하는 테스트 경로 찾기:
- 모든 분기(엣지)를 최소 1번씩 통과해야 함
- 보통 2개 경로로 커버 가능
```

> [!example] 기출 (2023년 1회차 19번, 2025년 2회차 11번)
> 분기 커버리지 = 모든 분기(참/거짓 경로)를 최소 1번씩

## 스텁 (Stub) & 드라이버 (Driver)

> [!tip] 방향 기억법
> - **하향식** ↓ 테스트 → 아래(하위)가 없음 → **스텁**으로 채움
> - **상향식** ↑ 테스트 → 위(상위)가 없음 → **드라이버**로 채움

| 구분 | 스텁 (Stub) | 드라이버 (Driver) |
|------|------------|-----------------|
| **테스트 방향** | 하향식 (Top-Down) | 상향식 (Bottom-Up) |
| **대리 역할** | 하위 모듈 대리 | 상위 모듈 대리 |
| **기능** | 단순한 결과값만 반환 | 입출력 제어 |
| **서버-클라이언트 비유** | 가상 클라이언트 | 가상 서버 |

> [!example] 기출 (2026년 1회차 19번, 2023년 2회차 20번)
> - 스텁: "하위 모듈을 대신하여 단순한 결과값만 반환"
> - 드라이버: "상위 모듈을 대신하여 하위 모듈의 입력/출력 확인"

## 블랙박스 테스트 기법

| 기법 | 설명 |
|------|------|
| **동치 분할 (Equivalence Partitioning)** | 유사한 입력값을 그룹으로 나눠 대표값만 테스트 |
| **경계값 분석 (Boundary Value Analysis)** | 경계(최소/최대)에서 오류 가능성 높음 |
| **원인-효과 그래프** | 원인(입력) → 효과(출력) 관계 표현 |

> [!example] 기출 (2023년 3회차 16번)
> "유사한 입력값이 유사한 답변 → 하나가 그 분할 내 모든 값 대표" → **동치 분할(Equivalence Partitioning)**
