# 정보처리기사 실기 2026 Study Vault

정보처리기사 실기 시험 대비를 위한 학습 노트 저장소입니다.

## 구성

| 폴더 | 내용 |
|------|------|
| `00-Dashboard/` | 학습 로드맵, 빠른 참조표, 시험 함정 정리 |
| `01-프로그래밍/` | C언어 · Java · Python 핵심 문법 및 연습문제 |

| `03-소프트웨어공학/` | SW공학, 디자인패턴, 응집도/결합도, 테스트 |

| `05-네트워크/` | 네트워크 개념, IP/서브넷, 오류제어, 연습문제 |
