# SQL / 데이터베이스 연습문제

---

## SQL 쿼리

**Q1.** 아래 테이블에서 부서별 평균 급여가 300 이상인 부서의 부서명과 평균 급여를 출력하는 쿼리를 작성하시오.
```
테이블: 직원(사번, 이름, 부서명, 급여)
```

> [!answer]- 정답 보기
> ```sql
> SELECT 부서명, AVG(급여) AS 평균급여
> FROM 직원
> GROUP BY 부서명
> HAVING AVG(급여) >= 300;
> ```
> WHERE가 아닌 **HAVING** — 집계 함수 조건은 HAVING

**Q2.** 다음 쿼리의 출력 결과는? (2024년 2회차 6번)
```sql
SELECT COUNT(DISTINCT 학과)
FROM 학생
WHERE 성별 = '남';
```
테이블: 학생(학번, 이름, 학과, 성별)
데이터: CS-남, CS-남, EE-남, IS-여, CS-여

> [!answer]- 정답 보기
> WHERE 성별='남' → CS, CS, EE  
> DISTINCT 학과 → CS, EE  
> COUNT → **2**

**Q3.** 다음 SQL의 실행 결과에서 출력될 행 수는? (2025년 3회차 6번)
```sql
-- 학생 테이블: 4개 행 (CS, CS, EE, ME)
-- 수강 테이블: 3개 행 (CS, EE, CS)
SELECT 학생.이름, 수강.과목
FROM 학생 INNER JOIN 수강
ON 학생.학과 = 수강.학과;
```

> [!answer]- 정답 보기
> CS학생(2명) × CS수강(2개) = 4  
> EE학생(1명) × EE수강(1개) = 1  
> ME는 수강에 없음 = 0  
> 총 **5행**

**Q4.** 다음 중 INNER JOIN과 CROSS JOIN의 차이를 서술하시오.

> [!answer]- 정답 보기
> - **INNER JOIN**: ON 조건 일치 행만 반환 (교집합적 결합)
> - **CROSS JOIN**: 모든 행의 조합 (카테시안 곱), 조건 없음
> 예: A(3행) × B(4행) → CROSS JOIN = 12행

**Q5.** 다음 쿼리에서 빈칸에 알맞은 절은?
```sql
SELECT 학과, COUNT(*) AS 학생수
FROM 학생
___________
ORDER BY 학생수 DESC;
```
※ 각 학과별 학생 수를 출력

> [!answer]- 정답 보기
> **GROUP BY 학과**

**Q6.** 다음 서브쿼리의 출력 결과는? (2023년 1회차 4번)
```sql
-- 학생(학번, 이름, 학과, 학년, 성적)
SELECT 이름 FROM 학생
WHERE 성적 > (SELECT AVG(성적) FROM 학생);
```
성적: 홍길동=90, 이순신=80, 유관순=70, 강감찬=60

> [!answer]- 정답 보기
> AVG(성적) = (90+80+70+60)/4 = 75  
> 성적 > 75 → 홍길동(90), 이순신(80)  
> 출력: **홍길동, 이순신**

## DDL / 제약조건

**Q7.** 다음 DDL에서 ①~④에 알맞은 내용을 채우시오.
```sql
CREATE TABLE 주문(
    주문번호 INT ( ① ),
    고객번호 INT NOT NULL,
    주문일 DATE,
    ( ② ) KEY (주문번호),
    ( ③ ) KEY (고객번호) ( ④ ) 고객(고객번호)
        ON DELETE CASCADE
);
```

> [!answer]- 정답 보기
> ① **NOT NULL** (또는 PRIMARY KEY이면 자동 NOT NULL)  
> ② **PRIMARY**  
> ③ **FOREIGN**  
> ④ **REFERENCES**

**Q8.** CASCADE와 RESTRICT의 차이점을 서술하시오.

> [!answer]- 정답 보기
> - **CASCADE**: 부모 레코드 삭제 시 참조하는 자식 레코드도 자동 삭제
> - **RESTRICT**: 자식이 참조 중이면 부모 삭제 금지 (오류 발생)

## 관계대수

**Q9.** 관계대수 기호 σ, π, ⋈ 의 명칭과 의미를 서술하시오.

> [!answer]- 정답 보기
> - **σ (시그마)**: 선택(Selection) — 조건을 만족하는 행 선택 = WHERE
> - **π (파이)**: 투영(Projection) — 특정 속성(열)만 추출 = SELECT 컬럼
> - **⋈ (활꼴)**: 조인(Join) — 두 릴레이션 연결

**Q10.** 자연조인(Natural Join)과 동등조인(Equi Join)의 차이점은?

> [!answer]- 정답 보기
> - **동등조인(Equi Join)**: `=` 조건으로 조인, **중복 컬럼 포함** 출력
> - **자연조인(Natural Join)**: 동등조인에서 **중복 컬럼 제거** 후 출력
> 자연조인 ⊂ 동등조인

## 정규화

**Q11.** 아래 릴레이션에서 어떤 정규형 위반이 있는지 설명하시오.
```
성적(학번, 과목코드, 학과, 학년, 성적)
기본키: (학번, 과목코드)
FD: 학번 → 학과, 학번 → 학년  (부분 종속)
```

> [!answer]- 정답 보기
> 기본키가 (학번, 과목코드)인데 학과/학년은 학번에만 종속 → **부분 함수적 종속**  
> **2NF 위반**  
> 해결: (학번, 과목코드, 성적) + (학번, 학과, 학년) 분리

**Q12.** 3NF를 만족하는 릴레이션이 BCNF를 위반하는 경우는 어떤 경우인가?

> [!answer]- 정답 보기
> 결정자(A→B에서 A)가 **후보키가 아닌** 경우  
> 즉, 일반 속성이 다른 속성을 결정하는 관계가 있을 때  
> 3NF: 이행 종속 없음 → OK, BCNF: 결정자=후보키 → NG

## DB 개념

**Q13.** 기본키(Primary Key)와 후보키(Candidate Key)의 관계를 설명하시오.

> [!answer]- 정답 보기
> - **후보키**: 유일성 + 최소성 만족하는 키 집합 (여러 개 가능)
> - **기본키**: 후보키 중 **대표로 선택**된 하나
> - 대체키 = 기본키로 선택되지 않은 나머지 후보키

**Q14.** 참조 무결성이 위반되는 상황 2가지를 설명하시오.

> [!answer]- 정답 보기
> 1. 자식 테이블에 부모 PK에 **없는 값**을 외래키로 입력  
> 2. 부모 레코드를 삭제하는데 자식이 그 PK를 **참조 중**인 경우 (CASCADE/RESTRICT 없을 때)

**Q15.** 다음 중 인덱스(Index)의 특징이 아닌 것은?
① 검색 속도를 향상시킨다  
② 항상 정렬된 상태를 유지한다  
③ INSERT/UPDATE/DELETE 성능을 향상시킨다  
④ `<키 값, 포인터>` 구조로 구성된다

> [!answer]- 정답 보기
> **③** — 인덱스는 INSERT/UPDATE/DELETE 시 인덱스도 갱신해야 하므로 **DML 성능 저하** 가능

**Q16.** VIEW(뷰)의 특징을 3가지 이상 설명하시오.

> [!answer]- 정답 보기
> 1. 가상 테이블 — 실제 데이터 미보유, 쿼리로 정의
> 2. 독립성 — 원본 테이블 구조 변경 시 응용 프로그램 영향 최소화
> 3. 보안성 — 특정 컬럼/행만 공개 가능
> 4. `DROP VIEW 뷰명 CASCADE` — 연관 뷰도 함께 삭제
