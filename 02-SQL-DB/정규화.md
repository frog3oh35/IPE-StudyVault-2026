# 정규화 (Normalization)

> [!important] 출제 빈도 ★★★★
> 정규화 단계별 조건 + 반정규화 목적

---

## 정규화 핵심 개념

- **목적**: 데이터 중복 제거, 이상현상(Anomaly) 방지
- **이상현상 종류**: 삽입 이상 / 갱신 이상 / 삭제 이상

---

## 정규화 단계

```
비정규 릴레이션
   ↓ 도메인이 원자값
1NF (제1정규형)
   ↓ 부분 함수적 종속 제거
2NF (제2정규형)
   ↓ 이행적 함수적 종속 제거
3NF (제3정규형)
   ↓ 결정자가 후보키 아닌 함수 종속 제거
BCNF (Boyce-Codd 정규형)
   ↓ 다치 종속 제거
4NF
   ↓ 조인 종속 제거
5NF (완전 정규형)
```

---

## 1NF — 제1정규형

**조건**: 속성값이 모두 **원자값(Atomic Value)**

- 다중값 속성 X (예: {수학, 영어} → 행 분리)
- 반복 그룹 속성 X

| 학번 | 과목 |
|------|------|
| 001 | 수학 |
| 001 | 영어 |

> 1NF 만족 — 각 행이 하나의 과목만

---

## 2NF — 제2정규형

**조건**: 1NF 충족 + **부분 함수적 종속 제거** → 완전 함수적 종속

- **부분 종속**: 기본키의 일부에만 종속되는 속성 존재 시 위반
- 기본키가 단일 속성이면 자동으로 2NF

> [!example] 예시
> 기본키 = (학번, 과목)  
> 학년은 학번에만 종속 → 부분 종속 → **2NF 위반**  
> 분리: (학번, 과목, 성적) + (학번, 학년)

---

## 3NF — 제3정규형

**조건**: 2NF 충족 + **이행적 함수적 종속 제거**

- **이행적 종속**: A→B이고 B→C이면 A→C (B가 키가 아닌 경우)
- 일반 속성이 일반 속성을 결정하면 위반

> [!example] 예시
> 학번 → 학과코드 → 학과명  
> 학과명이 학번에 이행 종속 → **3NF 위반**  
> 분리: (학번, 학과코드) + (학과코드, 학과명)

> [!example] 기출 (2025년 1회차 15번)
> "이행적 함수 종속을 제거하는 정규화 단계" → **3NF**

---

## BCNF

**조건**: 3NF 충족 + 모든 **결정자(Determinant)가 후보키**

- 3NF를 만족해도 결정자가 후보키가 아니면 BCNF 위반
- 3NF와 BCNF는 다른 단계임!

> [!example] 기출 (2024년 3회차 17번)
> "모든 결정자가 후보키인 정규형" → **BCNF**

---

## 정규화 단계 암기법

| 단계 | 제거 대상 | 키워드 |
|------|-----------|-------|
| 1NF | 비원자값 | **원자값** |
| 2NF | 부분 함수적 종속 | **부분 → 완전** |
| 3NF | 이행적 함수적 종속 | **이행 제거** |
| BCNF | 결정자가 후보키 아닌 FD | **결정자=후보키** |

> [!tip] 암기: **1(원) 2(부) 3(이) B(결)** — 1원2부3이B결

---

## 반정규화 (Denormalization)

> [!warning] 반정규화 ≠ 정규화 실패. 의도적인 성능 최적화임

**목적**: 조회 성능 향상 (JOIN 횟수 감소)

**방법**:
- 테이블 **병합** (1:1 또는 1:N 관계 테이블 합치기)
- 테이블 **분할** (수평/수직 분할)
- 중복 컬럼 추가 (계산 결과 미리 저장)
- 파생 테이블 추가 (집계 테이블)

> [!example] 기출 (2026년 1회차 16번, 2025년 2회차 5번)
> "테이블 조회 성능 향상을 위해 정규화를 의도적으로 역행" → **반정규화(역정규화)**
