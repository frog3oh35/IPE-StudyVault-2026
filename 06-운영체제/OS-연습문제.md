## CPU 스케줄링

**Q1.** 다음 설명에 해당하는 스케줄링 알고리즘은? (2025년 2회차 4번)
> "준비 큐에 있는 프로세스 중 남은 실행 시간이 가장 짧은 프로세스를 선점하여 CPU를 배정"

> [!answer]- 정답 보기
> **SRT (Shortest Remaining Time)**  
> SJF의 선점형 버전. 새 프로세스가 도착할 때마다 남은 시간 비교.

**Q2.** 다음 설명에 해당하는 스케줄링 알고리즘은?
> "각 프로세스에 동일한 CPU 시간(타임 퀀텀)을 할당하고 할당 시간이 지나면 다음 프로세스로 넘어가는 순환 방식"

> [!answer]- 정답 보기
> **RR (Round Robin)**  
> 선점형, 시분할 시스템에 적합, 타임 퀀텀 크기가 성능에 큰 영향

**Q3.** 다음 프로세스에 대해 RR(타임퀀텀=2)의 평균 대기시간을 계산하시오.

| 프로세스 | 도착 | 실행 |
|---------|------|------|
| P1 | 0 | 4 |
| P2 | 0 | 3 |
| P3 | 0 | 5 |

> [!answer]- 정답 보기
> 간트 차트:
> ```
> 0~2: P1(남2), 2~4: P2(남1), 4~6: P3(남3),
> 6~8: P1(완료✓ t=8), 8~9: P2(완료✓ t=9),
> 9~11: P3(남1), 11~12: P3(완료✓ t=12)
> ```
> 대기시간 = 완료시간 - 도착시간 - 실행시간  
> P1: 8-0-4=4, P2: 9-0-3=6, P3: 12-0-5=7  
> 평균: (4+6+7)/3 = **17/3 ≈ 5.67ms**

**Q4.** 다음 프로세스에 대해 SJF (비선점)의 평균 대기시간을 계산하시오.

| 프로세스 | 도착 | 실행 |
|---------|------|------|
| P1 | 0 | 6 |
| P2 | 2 | 4 |
| P3 | 4 | 2 |

> [!answer]- 정답 보기
> t=0: P1 시작 (비선점, P1 완료까지 기다림)
> t=6: P1 완료. 준비큐 = P2(남4), P3(남2) → P3가 더 짧음 → P3 선택
> t=8: P3 완료 → P2 선택
> t=12: P2 완료
>
> 대기시간: P1=0, P3=(6-4)=2, P2=(8-2)=6  
> 평균: (0+2+6)/3 = **8/3 ≈ 2.67ms**

## 페이지 교체

**Q5.** LRU와 LFU 알고리즘의 차이점을 설명하시오.

> [!answer]- 정답 보기
> - **LRU (Least Recently Used)**: 가장 오랫동안 **사용하지 않은** 페이지 교체 → 시간 기준
> - **LFU (Least Frequently Used)**: 사용 **횟수가 가장 적은** 페이지 교체 → 빈도 기준  
> LRU가 일반적으로 더 우수한 성능

**Q6.** 다음 페이지 참조열에서 LRU, 프레임 3개일 때 페이지 부재 횟수는?
페이지 참조: 7 0 1 2 0 3 0 4

> [!answer]- 정답 보기
> ```
> 7: [7] 부재 (1)
> 0: [7,0] 부재 (2)
> 1: [7,0,1] 부재 (3)
> 2: [0,1,2] 부재 — 7 교체 (가장 오래) (4)
> 0: [0,1,2] 적중 (참조됨)
> 3: [0,2,3] 부재 — 1 교체 (5)
> 0: [0,2,3] 적중
> 4: [0,3,4] 부재 — 2 교체 (6)
> ```
> 페이지 부재: **6회**

**Q7.** FIFO 알고리즘에서 나타나는 Belady의 이상 현상(Anomaly)을 설명하시오.

> [!answer]- 정답 보기
> 일반적으로 프레임 수가 늘어나면 페이지 부재가 줄어야 하지만,
> **FIFO에서는 프레임 수를 늘려도 페이지 부재가 오히려 증가**하는 현상
> → LRU/OPT에서는 발생하지 않음

## 프로세스 / 운영체제 개념

**Q8.** 프로세스와 스레드(Thread)의 차이점은?

> [!answer]- 정답 보기
> - **프로세스**: 독립적인 메모리 공간(코드/데이터/스택/힙)을 가진 실행 단위
> - **스레드**: 프로세스 내 실행 흐름 단위, 같은 프로세스의 메모리 **공유**
> - 스레드 간 문맥 전환이 프로세스 전환보다 빠름 (가벼운 프로세스)

**Q9.** 교착 상태(Deadlock) 발생의 4가지 필요 조건은?

> [!answer]- 정답 보기
> 1. **상호 배제 (Mutual Exclusion)**: 자원은 한 번에 한 프로세스만 사용
> 2. **점유 대기 (Hold & Wait)**: 자원 점유 중에 다른 자원 대기
> 3. **비선점 (No Preemption)**: 사용 중인 자원 강제 해제 불가
> 4. **환형 대기 (Circular Wait)**: 프로세스들이 원형으로 서로의 자원 대기
>
> **암기**: **상점비환** (상점에서 비환전)

**Q10.** 다음 스케줄링 방식은 선점형인가 비선점형인가?
① FCFS  ② SRT  ③ SJF  ④ RR

> [!answer]- 정답 보기
> ① FCFS — **비선점**  
> ② SRT — **선점** (SJF의 선점 버전)  
> ③ SJF — **비선점** (기본은 비선점)  
> ④ RR — **선점**

## 종합

**Q11.** 스래싱(Thrashing)이란 무엇이며 어떻게 해결하는가?

> [!answer]- 정답 보기
> **스래싱**: 다중 프로그래밍 정도가 너무 높아 페이지 교체가 과도하게 발생하여 CPU 이용률이 급격히 떨어지는 현상  
> **해결**: 워킹셋 모델 적용, 다중 프로그래밍 정도 감소, 프레임 추가 할당

**Q12.** 가상 메모리(Virtual Memory)의 핵심 원리와 이점을 서술하시오.

> [!answer]- 정답 보기
> - **원리**: 보조기억장치를 메인메모리처럼 사용, 요구 페이징으로 필요 시에만 로드
> - **이점**: 실제 메모리보다 큰 프로세스 실행 가능, 다중 프로그래밍 지원
