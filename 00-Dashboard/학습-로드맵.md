# 🗺️ 정보처리기사 실기 — 학습 로드맵

> **학습 전략**: 기출문제(2023~2026) 10회차 분석 → 자주 나오는 것부터 → 핵심요약 이론 → 코드 실습

## 📊 출제빈도 우선순위 (기출 10회차 분석)

### ★★★★★ 1순위 — 매 회차 반드시 출제 (40점 이상)

| 주제 | 폴더 | 출제 패턴 |
|------|------|-----------|
| **C언어 코드 출력** | [[C언어-핵심]] | 2~3문제/회차. 포인터, 구조체, 재귀, 비트연산 |
| **Java 코드 출력** | [[Java-핵심]] | 2~4문제/회차. 상속/오버라이딩, 예외처리, static |
| **Python 코드 출력** | [[Python-핵심]] | 1~2문제/회차. 슬라이싱, 딕셔너리, 클래스 |
| **SQL** | [[SQL-핵심]] | 2~3문제/회차. SELECT/JOIN/GROUP BY/서브쿼리 |
| **디자인 패턴** | [[디자인패턴]] | 1~2문제/회차. GoF 23가지 패턴 식별 |
| **IP/서브넷 계산** | [[IP-서브넷]] | 1~2문제/회차. CIDR, 네트워크 주소 계산 |

### ★★★★ 2순위 — 거의 매 회차 (20~30점)

| 주제 | 폴더 |
|------|------|
| 접근 제어 (MAC / DAC / RBAC) | [[접근제어]] |
| 보안 공격 기법 (SYN Flooding, APT, 워터링홀 등) | [[공격기법]] |
| 악성코드 분류 (웜/트로이목마/바이러스/루트킷) | [[공격기법]] |
| 암호화 알고리즘 (AES, DES, RSA, ECC) | [[암호화]] |
| 응집도 / 결합도 | [[응집도-결합도]] |
| 테스트 커버리지 (문장/분기/조건/MC-DC) | [[테스트]] |
| CPU 스케줄링 (RR, SJF, SRT) | [[CPU-스케줄링]] |
| 오류 검출/수정 (CRC, Hamming, FEC, BEC) | [[오류제어]] |

### ★★★ 3순위 — 2~3 회차마다 출제

| 주제 | 폴더 |
|------|------|

| HDLC 프레임 (정보/감독/비번호, 균형/응답 모드) | [[네트워크-개념]] |

## 🛣️ 권장 학습 순서

```
1단계: 로드맵 파악 → 지금 여기!
2단계: 1순위 이론 학습 (SQL, 디자인패턴, 접근제어, 테스트)
3단계: 1순위 프로그래밍 (C언어 → Java → Python)
4단계: 2순위 이론 (보안, 네트워크)
5단계: 3순위 이론 (OS, 나머지 DB)
6단계: 기출문제 풀이 → 약점 재복습
```
