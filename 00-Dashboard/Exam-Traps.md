## 💻 프로그래밍 함정

> [!warning]- Java 오버라이딩 vs 오버로딩 함정
> **함정**: `A a = new B();` 에서 어떤 메서드가 호출되는가?
> - 런타임 다형성: **실제 객체(B)의 메서드**가 호출됨
> - 단, `static 메서드`는 참조 타입(A)의 메서드가 호출됨
> - `a.id()` → static이므로 **A.id()** 호출
> - 2026년 1회차 7번, 2025년 2회차 10번, 2024년 3회차 11번에서 출제
>
> → [[Java-핵심]]

> [!warning]- Java `equals()` vs `==` 함정
> - `==`: 참조(주소) 비교
> - `equals()`: 내용(값) 비교
> - `new String("A") == "A"` → **false** (주소가 다름)
> - `new String("A").equals("A")` → **true**
> - 리터럴 `"A" == "A"` → **true** (String Pool에서 같은 객체)
>
> → [[Java-핵심]]

> [!warning]- C언어 포인터 `*p++` vs `(*p)++`
> - `*p++`: p가 가리키는 값을 읽고, **포인터 p를 증가**
> - `(*p)++`: **포인터 p가 가리키는 값**을 증가
>
> → [[C언어-핵심]]

> [!warning]- C언어 `switch` fall-through 함정
> - `break` 없으면 다음 case로 계속 실행됨
> - 2023년 2회차 5번에서 `case 11:` 이후 `default:`까지 모두 실행
>
> → [[C언어-핵심]]

> [!warning]- Python 슬라이싱 `[::-1]`
> - `lst[::-2]` : 뒤에서부터 2칸씩 → `[9, 7, 5, 3, 1]`
> - `lst[::2]` : 처음부터 2칸씩 → `[0, 2, 4, 6, 8]`
>
> → [[Python-핵심]]

## 🗄️ SQL/DB 함정

> [!warning]- `SELECT DISTINCT` vs `COUNT(DISTINCT ...)` 차이
> - `SELECT DISTINCT DEPT` → 중복 제거된 **행** 반환
> - `COUNT(DISTINCT DEPT)` → 중복 제거 후 **개수** 반환
> - 2026년 1회차 9번에서 혼동 유발
>
> → [[SQL-핵심]]

> [!warning]- `WHERE` vs `HAVING` 사용 위치
> - `WHERE`: 그룹화 **이전** 조건 (집계함수 사용 불가)
> - `HAVING`: 그룹화 **이후** 조건 (집계함수 사용 가능)
> - `GROUP BY` 없이 `HAVING` 단독 사용 가능하지만 드묾
>
> → [[SQL-핵심]]

> [!warning]- 카디널리티(Cardinality) vs 차수(Degree)
> - **카디널리티** = **행(튜플)의 수** (세로 개수)
> - **차수(Degree)** = **열(속성)의 수** (가로 개수)
> - 매우 자주 혼동! 반드시 암기
>
> → [[DB-개념]]

> [!warning]- 외래키 무결성 vs 개체 무결성
> - **개체 무결성**: 기본키(PK)는 NULL이거나 중복이면 안 됨
> - **참조 무결성**: 외래키는 참조 대상 릴레이션에 존재해야 함
> - **도메인 무결성**: 속성값은 도메인 범위 내에 있어야 함
>
> → [[DB-개념]]

## 🎨 소프트웨어 공학 함정

> [!warning]- 디자인 패턴 혼동 쌍
> | 혼동 쌍 | Bridge | Observer |
> |---------|--------|----------|
> | 2026년 1회차 | **기능과 구현 계층 분리** | **상태 변경 시 의존 객체 알림** |
>
> | 혼동 쌍 | Adapter | Proxy |
> |---------|---------|-------|
> | Adapter | 인터페이스 **변환** | 접근 **제어** / 대리 |
>
> → [[디자인패턴]]

> [!warning]- 응집도: 순차적 vs 교환적(통신적)
> - **순차적**: 출력이 다음 기능의 입력으로 연결 (파이프라인)
> - **교환적**: 같은 입출력으로 다른 기능 수행
> - 2026년 1회차 20번, 2024년 1회차 3번 출제
>
> → [[응집도-결합도]]

> [!warning]- 스텁과 드라이버 방향 헷갈림
> - **스텁(Stub)**: 하향식 ↓ → 하위 모듈이 없을 때 대리
> - **드라이버(Driver)**: 상향식 ↑ → 상위 모듈이 없을 때 대리
> - "하향식이면 하위가 없으니까 스텁으로 채운다"
>
> → [[테스트]]

> [!warning]- 조건 커버리지 ≠ 결정 커버리지
> - **결정(분기)**: 결정문 전체가 참/거짓 각 1번
> - **조건**: 각 개별 조건식이 참/거짓 각 1번
> - **조건/결정**: 둘 다 동시 만족
> - 조건 커버리지를 만족해도 결정 커버리지 불만족 가능!
>
> → [[테스트]]

## 🔐 보안 함정

> [!warning]- FEC vs BEC
> - **FEC (Forward Error Correction)**: 수신측이 **직접 수정** (재전송 없음)
>   → Hamming Code
> - **BEC (Backward Error Correction)**: 송신측에 **재전송 요청**
>   → CRC, Parity
>
> → [[오류제어]]

> [!warning]- 대칭키 vs 비대칭키 분류 암기
> - **대칭키**: DES, **AES**, **ARIA**, **SEED** (같은 키로 암호화+복호화)
> - **비대칭키**: **RSA**, **ECC** (공개키+개인키 쌍)
> - AES를 비대칭으로 착각하는 경우 多
>
> → [[암호화]]

## 📡 네트워크 함정

> [!warning]- 서브넷 계산 실수 포인트
> - 서브넷 마스크 `255.255.254.0` = `/23`
> - 네트워크 주소 = IP AND 서브넷마스크 (비트 AND 연산)
> - `192.168.11.20 AND 255.255.254.0` = `192.168.10.0`
>   - 11 = 00001011, 254 = 11111110 → AND = 00001010 = 10
>
> → [[IP-서브넷]]

> [!warning]- RIP vs OSPF
> - **RIP**: 거리 벡터, Hop Count 기반, 최대 15홉, IGP
> - **OSPF**: 링크 상태, Dijkstra 알고리즘, 제한 없음
>
> → [[네트워크-개념]]
