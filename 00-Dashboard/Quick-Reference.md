## 🔑 접근 제어 3종 → [[접근제어]]

| 이름 | 방식 | 키워드 |
|------|------|--------|
| **MAC** | 강제적 접근 통제 | 보안 등급, 군사/국가기밀, 중앙 설정 |
| **DAC** | 임의적 접근 통제 | 소유자가 권한 설정, 유연하지만 보안 낮음 |
| **RBAC** | 역할 기반 접근 통제 | 직무/역할에 따라 권한, 관리 용이 |

## 🧪 테스트 커버리지 → [[테스트]]

| 커버리지 | 설명 | 기출 키워드 |
|----------|------|-------------|
| **문장(Statement)** | 모든 문장 1회 이상 실행 | 구문 커버리지 |
| **분기(Branch)** | 모든 분기(결정포인트) 참/거짓 | =결정 커버리지 |
| **조건(Condition)** | 각 개별 조건식 참/거짓 | 결정과 다름! |
| **조건/결정** | 조건 + 결정 동시 만족 | |
| **MC/DC** | 각 조건이 독립적으로 결과에 영향 | 변경조건/결정 |
| **다중 조건** | 모든 조건 조합 | 경우의 수 가장 많음 |

- **스텁(Stub)**: 하향식 테스트 시 하위 모듈 대리 (결과값만 반환)
- **드라이버(Driver)**: 상향식 테스트 시 상위 모듈 대리 (입출력 제어)

## 📡 네트워크 오류 제어 → [[오류제어]]

| 방식 | 이름 | 설명 |
|------|------|------|
| **FEC** | 전진 오류 수정 | 재전송 없이 수신측 자체 수정 (Hamming) |
| **BEC** | 후진 오류 수정 | 오류 시 송신측에 재전송 요청 |
| **Hamming** | 해밍 코드 | FEC 방식, 1비트 오류 정정 가능 |
| **CRC** | 순환 중복 검사 | BEC 방식, 다항식으로 오류 검출 |
| **Parity** | 패리티 검사 | BEC 방식, 1비트 추가로 검출 |

## 🗄️ DB 핵심 용어 → [[DB-개념]]

| 용어 | 의미 |
|------|------|
| **튜플(Tuple)** | 행(Row), 레코드 |
| **속성(Attribute)** | 열(Column), 필드 |
| **카디널리티(Cardinality)** | 튜플의 수 (행 개수) |
| **차수(Degree)** | 속성의 수 (열 개수) |
| **인스턴스** | 현재 저장된 데이터 전체 |
| **스키마** | 데이터베이스 구조 정의 |

### 키(Key) 종류

| 키 | 설명 |
|----|------|
| **후보키** | 튜플을 유일하게 식별하는 최소 속성 집합 |
| **기본키(PK)** | 후보키 중 선택된 대표 키 |
| **대체키** | 후보키 중 기본키 제외한 나머지 |
| **슈퍼키** | 유일성은 만족, 최소성은 불필요 |
| **외래키(FK)** | 다른 릴레이션의 PK를 참조 |

## 🌐 보안 공격 기법 → [[공격기법]]

| 공격 | 설명 |
|------|------|
| **SYN Flooding** | SYN만 보내고 ACK 안 보냄 → 서버 대기큐 고갈 |
| **스머프(Smurf)** | ICMP Echo Reply를 대량 발송 → DoS |
| **세션 하이재킹** | 세션 상태를 훔쳐 인증 없이 통신 탈취 |
| **워터링홀** | 자주 방문하는 합법 사이트에 악성코드 삽입 |
| **APT** | 장기간 특정 표적 집중 공격 |
| **심볼릭링크** | 임시 파일을 특수 파일로 교체하는 경쟁 조건 |

### 악성코드 분류

| 종류 | 특징 |
|------|------|
| **바이러스** | 정상 파일에 기생, 자가복제 |
| **웜** | 독자 실행, 네트워크로 전파 |
| **트로이목마** | 정상 프로그램 위장, 자가복제 없음 |
| **루트킷** | 존재 자체를 숨김, 시스템 깊숙이 |
| **랜섬웨어** | 파일 암호화 후 돈 요구 |
| **스파이웨어** | 사용자 정보 수집 전송 |

## 📶 HDLC 프레임 → [[네트워크-개념]]

| 프레임 | 첫 비트 | 역할 |
|--------|---------|------|
| **정보(I)** | 0 | 실제 데이터 전송 |
| **감독(S)** | 10 | 흐름제어, 오류제어 |
| **비번호(U)** | 11 | 순서번호 없음, 링크 설정/해제 |

| 모드 | 설명 |
|------|------|
| **비동기 균형 모드(ABM)** | 두 국이 동등, 명령/응답 주고받음 |
| **비동기 응답 모드(ARM)** | 종국이 허가 없이 응답 가능 |
