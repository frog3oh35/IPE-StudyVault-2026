# 2026-09-18 수준체크 오답 리뷰

> ⚠️ 참고: tutor 스킬은 문제 원문·보기·제출 답을 따로 저장하지 않고, 개념 단위 오답 메모(헷갈린 점 + 핵심)만 기록해요. 아래 "문제"는 그 메모를 바탕으로 재구성한 예시이며, 실제 화면에 떴던 문항 문구와는 다를 수 있어요.

## 1. [01-프로그래밍] static vs 인스턴스 메서드 바인딩

**문제 (재구성 예시)**
부모 클래스와 자식 클래스에 동일한 시그니처의 static 메서드가 각각 정의되어 있다. 부모 타입 참조변수가 자식 인스턴스를 가리키고 있을 때, 이 참조변수로 static 메서드를 호출하면 어떤 메서드가 실행되는가?

**내 답 (오답)**
자식 클래스의 static 메서드가 실행된다 — 인스턴스 메서드처럼 실제 객체 타입을 기준으로 오버라이딩되어 호출된다고 판단.

**해설**
- static 메서드는 인스턴스 메서드와 달리 **런타임(동적) 바인딩이 아니라 컴파일타임(정적) 바인딩**이다.
- 참조변수의 **선언 타입(참조 타입)** 기준으로 어떤 static 메서드를 호출할지 결정된다.
- 따라서 이건 오버라이딩(overriding)이 아니라 **숨김(hiding)**이며, 부모 타입 참조로 호출하면 **부모 클래스의 static 메서드**가 실행된다.

## 2. [02-SQL-DB] COUNT(DISTINCT) 집계함수

**문제 (재구성 예시)**
`WHERE` 조건으로 필터링한 뒤 특정 컬럼에 `COUNT(DISTINCT 컬럼명)`을 적용하는 쿼리가 있다. 필터링 결과 남은 행이 여러 개지만 해당 컬럼의 값이 모두 동일하다면, 쿼리 결과는 무엇인가?

**내 답 (오답)**
WHERE로 필터링된 행의 개수(예: 50)를 결과로 착각.

**해설**
- SQL 실행 순서상 **WHERE가 먼저 적용**되어 대상 행이 줄어든다.
- 그다음 `COUNT(DISTINCT 컬럼)`은 남은 행들 중 **컬럼 값의 "서로 다른 개수"** 를 센다.
- 필터링 후 남은 행들의 값이 전부 같다면, 행이 몇 개든 관계없이 **결과는 1**이다.

## 3. [03-소프트웨어공학] 응집도 종류 구분 (교환적 vs 절차적)

**문제 (재구성 예시)**
한 모듈 내 여러 기능이 특정 순서에 따라 순차적으로 수행되지만, 서로 같은 입력이나 출력을 공유하지는 않는다. 이 모듈의 응집도 유형은?

**내 답 (오답)**
"순서대로 수행된다"는 표현만 보고 교환적(통신적) 응집도로 판단.

**해설**
- **교환적(통신적) 응집도**의 판별 기준은 순서가 아니라, 여러 기능이 **동일한 입력/출력(데이터)을 공유**하는지 여부다.
- **절차적 응집도**는 입출력 공유 없이 **단순히 순서 관계**만 있는 경우다.
- 따라서 "순서대로 수행"이라는 키워드만으로 판단하면 안 되고, **데이터 공유 여부**를 먼저 확인해야 한다.
