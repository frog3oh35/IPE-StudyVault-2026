# 암호화 & 보안 프로토콜

> [!important] 출제 빈도 ★★★★
> 대칭키/비대칭키 분류, SSH/VPN/OAuth 설명 식별

---

## 암호화 알고리즘 분류

### 대칭키 (비밀키) — 암호화/복호화에 같은 키 사용

| 알고리즘 | 키 길이 | 특징 |
|----------|--------|------|
| **DES** | 56비트 | 구형, 취약 |
| **AES** | 128/192/256비트 | DES 대체, 현재 세계 표준, NIST 1997년 제정 |
| **ARIA** | 128비트 | 대한민국 표준 암호화 |
| **SEED** | 128비트 | 대한민국 표준 (한국인터넷진흥원) |
| **3DES** | 168비트 | DES를 3번 적용 |

### 비대칭키 (공개키) — 공개키로 암호화, 개인키로 복호화

| 알고리즘 | 기반 | 특징 |
|----------|------|------|
| **RSA** | 소인수분해 | 가장 널리 사용, 느림 |
| **ECC** | 타원 곡선 | 짧은 키로 높은 보안, 빠름 |
| **ElGamal** | 이산 대수 | |

> [!example] 기출 (2023년 2회차 15번)
> 대칭키: DES, AES, ARIA, SEED
> 비대칭키: RSA, ECC

> [!example] 기출 (2024년 2회차 7번)
> "1997년 NIST에서 DES를 대체하기 위해 생성, 128/192/256비트 가변 키" → **AES**

## 해시 (Hash)

- 임의 크기 데이터를 **고정 크기 데이터**로 변환 (단방향)
- 키-값 쌍 저장, 평균 시간복잡도 O(1)
- MD5, SHA-256 등

> [!example] 기출 (2023년 2회차 16번)
> "임의 크기 데이터를 고정 크기 데이터로 변화시켜 저장" → **해시(Hash)**

## 네트워크 보안 프로토콜

### SSH (Secure Shell)

- **암호화된 원격 접속** 프로토콜
- 기본 포트: **22**
- **공개키 기반** 인증 방식
- Telnet의 보안 취약점 보완
- rsh, rcp, rlogin, ftp 등의 보안 버전 제공
- **IP 스푸핑 방지** 기능

> [!example] 기출 (2025년 2회차 3번, 2023년 1회차 7번)
> "암호화된 원격 접속, 포트 22번, 공개키 기반, Telnet 대체" → **SSH**

### VPN (Virtual Private Network)

- 공용 네트워크를 통해 **사설 네트워크 확장**
- 사용자 IP 주소 숨김
- 종류: **IPSec**, **SSL**, **L2TP**

> [!example] 기출 (2024년 3회차 17번) → **VPN** (3글자)

### IPSec

- **네트워크 계층(3계층)** IP 패킷 암호화/인증
- 기업 VPN 구현에 사용
- **AH (Authentication Header)** + **ESP (Encapsulating Security Payload)**

> [!example] 기출 (2024년 2회차 5번)
> "Network layer에서 IP패킷 암호화, VPN 구현, AH와 ESP 두 프로토콜" → **IPSec**

### L2TP (Layer 2 Tunneling Protocol)

- 2계층(데이터링크) 터널링 기술
- **L2F + PPTP** 결합
- IPSec와 함께 사용하면 더 안전

> [!example] 기출 (2023년 1회차 6번)

### OAuth

- 비밀번호 없이 **제3자 앱에 접근 권한 위임**
- **Access Token** 발급
- 소셜 로그인 (Facebook, Google, Twitter)의 기반
- SSO와 차이: **서로 다른 서비스 간** 권한 위임 (SSO는 같은 시스템 내 인증)

> [!example] 기출 (2025년 3회차 13번, 2023년 3회차 2번)
> "비밀번호 전달 없이, Access Token으로 제3자에 권한 위임, 소셜 로그인" → **OAuth**

### OTP (One-Time Password)

- 한 번 사용 후 즉시 폐기 → **재사용 불가**
- 시간 동기화 또는 카운터 기반으로 값 생성
- **재전송 공격 방지**
- 은행 인증 등 고보안 영역

> [!example] 기출 (2025년 3회차 11번)
