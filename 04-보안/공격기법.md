## 네트워크 공격 기법

### SYN Flooding

- TCP **3-way-handshake 취약점** 악용
- 공격자가 수많은 **SYN 패킷**을 보내고 **ACK를 고의로 안 보냄**
- 서버의 **연결 대기 큐(backlog queue)** 가득 참
- 정상적인 접속 요청 처리 불가 → **DoS(서비스 거부)**

> [!example] 기출 (2025년 2회차 19번)
> "SYN 패킷을 전송 후 ACK를 고의로 보내지 않아 서버 연결 대기 큐 고갈" → **SYN Flooding**

### 스머프 (Smurf / Smurfing)

- **IP/ICMP** 특성 악용
- 공격 대상 호스트 IP를 소스로 위장 → 브로드캐스트로 **ICMP Echo Request** 전송
- 모든 호스트가 **ICMP Echo Reply**를 공격 대상에게 보냄 → DoS
- 대량의 ICMP 패킷으로 서비스 불능

> [!example] 기출 (2024년 2회차 5번)
> "ICMP Echo Reply를 다량 발송하여 서비스 거부 유발" → **스머프(Smurf)**

### 세션 하이재킹 (Session Hijacking)

- "세션을 **가로채다**"
- TCP 3-way handshake 완료 후 **시퀀스 번호 조작**
- 정상적인 세션을 인증 없이 탈취

> [!example] 기출 (2025년 1회차 1번)
> "다른 사람의 세션 상태를 훔치거나 도용하여 액세스" → **세션 하이재킹**

### 워터링 홀 (Watering Hole)

- 불특정 다수 ❌ → **특정 조직/인물** 표적 공격
- 표적이 **자주 방문하는 합법적 웹사이트**에 악성코드 삽입
- 피해자는 **정상 사이트**를 방문했을 뿐 → 감염 사실 인지 어려움
- 접속자 IP/환경 확인 → 표적에게만 선택적 악성코드 실행

> [!example] 기출 (2026년 1회차 16번)
> "자주 방문하는 합법 사이트에 악성코드 삽입, 접속 시 자동 설치" → **워터링 홀**

### APT (Advanced Persistent Threat)

- **불특정 다수 ❌** → **명확한 표적** 집중
- **4단계**: 침투 → 검색 → 수집 → 유출
- **다양한 공격 기술** 사용 (Zero-day, 악성코드 등)
- 내부 직원 단말도 표적
- **장기간** 지속적 공격

> [!example] 기출 (2024년 1회차 17번)
> "명확한 표적, 다양한 보안 위협 기술, 침투/검색/수집/유출 4단계" → **APT**

### 심볼릭 링크 (Symbolic Link) 공격

- 원본 파일의 경로를 가리키는 **특수 파일(심볼릭 링크)** 생성
- 프로그램이 임시 파일 생성하는 순간을 틈타 **교체**
- 프로그램이 교체된 파일을 정상으로 인식하고 동작
- 이를 **경쟁 조건(Race Condition)** 공격이라고도 함

> [!example] 기출 (2026년 1회차 15번)
> "임시 파일을 미리 준비한 특수 파일로 교체" → **심볼릭 링크**

### ICMP 관련 공격

- **ICMP**: TCP/IP에서 IP 패킷 처리 시 문제를 알려주는 프로토콜
- **ICMP Flooding**: ping으로 연속 패킷 전송 → 서버 응답 과부하

> [!example] 기출 (2023년 1회차 10번) → **ICMP**

## 악성코드 분류

| 종류 | 자가복제 | 숙주 필요 | 네트워크 전파 | 특징 |
|------|---------|----------|--------------|------|
| **바이러스** | ✅ | ✅ (정상 파일에 기생) | ❌ | 감염 파일 없으면 실행 안 됨 |
| **웜** | ✅ | ❌ (독자 실행) | ✅ | 네트워크로 스스로 전파 |
| **트로이목마** | ❌ | - | - | 정상 프로그램 위장, 백도어 |
| **루트킷** | - | - | - | **존재 자체를 숨김**, 시스템 깊숙이 |
| **랜섬웨어** | - | - | - | 파일 암호화 후 금전 요구 |
| **스파이웨어** | - | - | - | 사용자 정보 수집/전송 |
| **스캐어웨어** | - | - | - | 공포로 속여 결제 유도, 가짜 바이러스 경고 |
| **애드웨어** | - | - | - | 광고 강제 표시 |

> [!example] 기출 (2023년 1회차 8번)
> 1. "독자적으로 실행, 네트워크 전파" → **웜**
> 2. "정상 프로그램 위장, 자가복제 없음, 백도어" → **트로이목마**
> 3. "정상파일에 기생, 자기복제, 숙주 없으면 실행 안 됨" → **바이러스**

> [!example] 기출 (2024년 1회차 15번)
> "인터넷 공격자의 존재를 숨기면서 무제한 접근 권한 부여, 시스템콜 해킹, 안티바이러스 탐지 우회" → **루트킷**

> [!example] 기출 (2025년 1회차 4번)
> "공포를 이용하여 대가 지불 또는 소프트웨어 설치 유도, 가짜 바이러스 경고" → **스캐어웨어**

## 소프트웨어 보안 기법

### 템퍼프루핑 (Tamper Proofing)

- 소프트웨어가 **불법으로 변경**되었을 때 정상 수행되지 않게 하는 기법
- **변조 검증 코드** 삽입
- 워터마크 삭제 방지, 역공학 방지

> [!example] 기출 (2023년 2회차 8번) → **템퍼프루핑**
