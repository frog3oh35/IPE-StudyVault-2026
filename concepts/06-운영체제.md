### 오답 메모

**페이지 교체 알고리즘 구분 (LRU/LFU/FIFO/OPT)**
- 2026-10-06: 프레임 3개, 참조열 1,2,3,4,1,2,5,1,2,3,4,5의 FIFO 페이지 부재 횟수 → 10으로 오답(정답 9). 10은 LRU 결과값 → 정의 구분(09-28 정답)은 되지만 **직접 계산할 때 FIFO와 LRU의 교체 기준이 섞임**
- 본인 분석: 다시 계산해 보니 정답이 나옴 (계산 실수). 앞으로 페이지 부재 계산은 **FIFO · LRU · LFU 세 방식 모두** 풀게 해서 방식 간 혼동 방지
- 핵심: FIFO는 적중(hit)해도 순서가 바뀌지 않음(먼저 들어온 것 교체), LRU는 적중 시 "최근 사용"으로 갱신. 표를 그려 프레임별로 들어온 순서를 추적. 이 참조열은 Belady의 모순 예제(FIFO 프레임 4개 → 10회)
- 2026-10-08 (세 방식 모두): 프레임 3, `7,0,1,2,0,3,0,4,2,3` → FIFO 6 / LRU 7 / LFU 8로 답함(정답 9 / 8 / 8). LFU만 정답. FIFO·LRU가 각각 정확히 정답보다 1~3 작음 → **처음 빈 프레임을 채우는 초기 부재 3회를 빼먹었을 가능성**. 다음엔 표를 그려 풀이 과정까지 확인

**HRN 스케줄링 우선순위 계산**
- 2026-10-08: 본인 "수업 때도 못 들어본 것 같다"며 모름 (정답 C: (20+5)/5 = 5)
- 핵심: 우선순위 = **(대기 시간 + 서비스 시간) ÷ 서비스 시간**, 클수록 먼저. SJF의 기아 현상 보완, 비선점

**프로세스 상태 전이 (Dispatch 등)**
- 2026-10-08: 실행 → 준비(시간 다 씀) → Dispatch로 오답(정답 Timer Run Out)
- 핵심: 준비→실행 Dispatch / 실행→준비 Timer Run Out / 실행→대기 Block / 대기→준비 Wake Up (대기에서 바로 실행 X)
